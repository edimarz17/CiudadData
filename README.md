# CiudadData
CiudadData API

CiudadData es una API diseñada para centralizar informacion urbana integrando distintas APIs externas.

Instalación y Ejecución
1. Instalar dependencias: npm install.
2. Configurar entorno: Crea un archivo .env con tus llaves de GeoNames, MTA y tu MONGO_URI como se muestra en el archivo de la carpeta config .
3. Iniciar el servidor: npm run dev.
4. Ejecutar pruebas: npm test.

Documentación
La documentación interactiva de Swagger está disponible en:
http://localhost:3000/api-docs.
